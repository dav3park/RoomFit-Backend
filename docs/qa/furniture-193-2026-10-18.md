# 가구 193개·설치 규칙 통합 검증

2026-10-18. 로컬 구현과 검증 기록입니다. 이 문서는 배포 전 검증 기록입니다. 배포 결과는 각 저장소의 GitHub Actions 실행에서 확인합니다.

## 구현

- 기존 93개 모델을 유지하고 제공된 ZIP의 C001–C100을 `expansion-c001`–`expansion-c100`으로 등록했습니다. 원본 parts·좌표·치수는 보존했습니다. 17개 기존 가구 종류에 추가되어 전체 종류는 21개입니다.
- mesh / sweep / profile 형상을 렌더러와 빌드 시 footprint 계산에서 같은 함수로 처리합니다. 원본 MIT 라이선스를 포함했습니다.
- 스타일·생활 방식과 설치 정책을 명시적 메타데이터로 연결했습니다. 스타일 분류는 추천을 위한 서비스 분류이며 제조사 인증 정보가 아닙니다.
- 커튼·블라인드는 실제 창 위치·방향·폭·높이·벽 두께에 맞게 배치합니다. 창 하나당 하나, 원본 대비 폭·높이 배율 0.5–2를 적용합니다. 창이 없거나 설치 공간이 부족한 경우 방 중앙에 대신 놓지 않습니다.
- 파티션과 양면 선반은 침대–책상/소파 사이 공간 분리 위치를 우선합니다. 협탁·커피 테이블·러그는 해당 생활 영역을 기준으로 후보를 만듭니다. 문 개폐·충돌·통로 검증을 계속 적용합니다.
- 탁상 조명·탁상 식물·화면은 확인된 상판과 높이를 사용합니다. 벽걸이·바닥/천장 고정형 가구를 구분하고, 받침을 제거한 경우 움직이지 않은 종속 가구도 재검증합니다. C003/C008의 곡면 상판과 C048의 불확실한 상부는 받침으로 임의 인정하지 않습니다.
- 후보 검색은 취향에 맞는 후보와 작은 후보, 설치 방식별 후보를 최대 8개까지 시도합니다. 사용자가 정확히 선택한 상품은 다른 상품으로 바꾸지 않습니다.
- 모델은 필요할 때 JSON 자산을 요청합니다. 동일 모델 요청은 공유하고 성공한 모델은 재사용합니다. 20초 제한·실패 표시·재시도를 제공하며, 재시도로 가구를 추가하지 않습니다. 초기 화면과 추천 Worker에 전체 mesh 데이터를 넣지 않습니다.

Java 21이 없는 로컬 환경에서 테스트/bootJar는 호출별 Java 25 init script로 검증했습니다. 저장소의 운영 toolchain 21 설정은 바꾸지 않았습니다.

서버의 이전 미커밋 안정화 수정은 보존했습니다. 새 카탈로그로 바뀌는 정상 상품 선택과 실제 설치 오류를 구분했고, 고정된 상품을 기대하는 단위 테스트의 기존 93개 카탈로그 전제는 전용 fixture로 분리했습니다. 실제 서비스·통합 테스트는 193개를 사용합니다.

독립 리뷰에서 찾은 상판/아래 선반 혼동, 전체 검증의 배열 순서 의존, 설치 높이를 무시한 창문 검사, 벽 없는 직사각형 fallback, 커튼의 벽 두께·본체 충돌 예외, 재시도 클릭 전파를 수정했습니다. 마지막 후속 리뷰에서 새 P1/P2 지적은 없었습니다.

## 성능·한계

동일한 공부/책장/식물 요청과 seed 41–50을 93개/193개 카탈로그에서 각각 10회 측정했습니다. 수치는 워밍업 후 로컬 CPU에서 엔진 계산만 측정하며 네트워크와 AI 응답 시간은 제외합니다. 측정 중앙값은 1.22초→1.97초, p95는 1.39초→2.15초였습니다. 원시 측정은 워크스페이스 `docs/ui-tooling/qa/furniture-193-2026-10-18/catalog-performance.json`에 있습니다. 추천은 Worker에서 계산합니다. 대형 모델 C098은 별도 JSON 약 7.8MiB로 필요할 때만 로드합니다. 저사양 모바일 실기기와 느린 네트워크는 미검증입니다.

사용자 승인 후 실제 AI 분석 API에 텍스트·사진·혼합을 각 3회 요청해 **9/9 HTTP 200**을 확인했습니다. 사진은 개인 정보가 없는 로컬 샘플 방 화면입니다. 각 응답을 193개 엔진에 연결한 **27개 추천안**에서 확인한 조건의 개수·제외·색감, 설치 위치, 본체 충돌·경계·문·창·통로 검사를 통과했습니다. 커튼과 파티션을 함께 요청한 별도 로컬 사례 3개도 통과했습니다. 일부 권장 접근 여유 공간에는 경고가 남을 수 있으며 본체 충돌과 구분합니다.

분석 응답은 텍스트 7.3–8.6초, 사진 11.6–20.0초, 혼합 10.5–13.4초였습니다. 이는 이번 3회씩의 관찰이며 이후 응답시간을 보장하지 않습니다. 사진에서 보이는 모든 물체가 필수 조건으로 추출되거나 사진과 동일한 공간이 재현된다는 뜻은 아닙니다. 방 저장·확정 API는 실행하지 않았습니다.

Web 저장소의 `docs/qa/live-consultation-193-responses.json`과 `live-consultation-193-results.json`에 승인된 테스트 입력·응답 및 후보별 감사 결과를 보관했습니다. `scripts/qa/liveConsultation193.test.ts`는 이 응답으로 네트워크 호출 없이 회귀 검증합니다. 테스트 실패를 허용하던 Backend CI 설정은 제거했습니다. 배포 전 CI의 운영 JDK 21 검사 결과도 확인합니다.

브라우저에는 기존 Three.Clock/PCFSoftShadowMap 폐기 예정 경고가 있습니다. 의도적으로 주입한 모델 요청 실패 외의 실제 작업실 실행 오류는 없었습니다. 개발용 단일 모델 검사 페이지의 favicon 404는 확인했으나 제품 코드와 무관합니다. 모델 100개의 캔버스 확인이 모든 시점·색상·실물 용도를 보장하지는 않습니다.
